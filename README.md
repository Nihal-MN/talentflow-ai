# TalentFlow AI

**Open-source AI-native hiring pipeline and explainable candidate matching platform.**

> 🚧 Work in progress — this repository is being built end-to-end: application code,
> tests, synthetic demo data and full documentation (architecture, AI design, API,
> Responsible AI, testing) are added as the build progresses.

TalentFlow AI ingests job descriptions and resumes, turns them into validated
structured talent data, performs explainable candidate-to-job matching, and lets a
recruiter manage candidates through a hiring pipeline — from NEW to HIRED — with
evidence, notes, tags and screening questions.

The complete README (problem statement, screenshots, architecture, quick start,
demo guide and roadmap) lands with the first release.
